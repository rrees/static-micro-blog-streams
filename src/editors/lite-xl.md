# LiteXL

Very small and minimal editor that feels a lot like Sublime Text.

Based on the editor [Lite](https://github.com/rxi/lite) which seems to be abandoned.

Relatively easy to build although I had to force compatability with SDL 2 on Raspbian. I ended up using the AppImage for x86.

The default scale choice on a Dell XPS was quite out of whack and setting the `LITE_SCALE` environment variable to 2 seemed a much more normal experience.
