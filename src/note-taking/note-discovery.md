# Note Discovery

This has become my main attempt to switch from Logseq to a web-based product.

## Organising information

Note Discovery supports tags, has folders and also bi-directional links. There are therefore a lot of ways to organise information that all overlaps to some extent.

Trying to put diverse areas of information into the same instance was a failure as having folders with hundreds of notes and overlapping tags made the system pretty unusable.

## Searching

By default the search searches inside notes and to search by note title you have to be in the folder view. This is quite fiddly and my default expectation is that sub-folders would be searched which doesn't seem to be true.

## Interface

I currently have 5 to 600 notes after importing a Logseq dataset and it feels like the interface is pretty useless when you have a lot of information. Fortunately the same search and create behaviour seems to work as in Logseq.

The interface is not great on small touch devices like phones with a hover effect requiring the long click to reveal small icons. The left-toolbar doesn't really translate well to small screens and the overall impression is that this is a web app that is focused on the desktop.

Moving notes requires using a drag and drop mechanism which is so fiddly and cumbersome it is actually easier to just change things on the file system (even if that means using SSH to access the remote filesystem). It is a bit crazy that there isn't a Move style command between folders.

Its redeeming grace is that writing seems quite pleasant.
