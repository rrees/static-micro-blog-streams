# QOwnNotes

Quite an ugly program that allows you to create Markdown notes with a simplified linking mechanism that allows you to use the standard Markdown link format but the relative file path to the Markdown file.

The application uses an SQLite database in addition to the flat files.

Emphasises AI integrations and usage tracking that feels a bit gross.
