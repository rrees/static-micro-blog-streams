# Uruky

A quirky independent search engine that values user privacy so much that you don't really have a conventional account but a user id which you buy pre-paid coupons for.

My first searches on Uruky were very good but then it has been a bit hit and miss.

It doesn't tend to bring up slop but it doesn't handle regionality very well.

It genuinely brings up some interesting content that has been buried under slop in the bigger search engines.
